# PTAGM — CAD 转角点坐标批量标注工具

![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)
![Version](https://img.shields.io/badge/Version-v2.1-brightgreen.svg)
![Language](https://img.shields.io/badge/Language-AutoLISP-orange.svg)
![Platform](https://img.shields.io/badge/Platform-AutoCAD%20%2F%20中望CAD%20%2F%20浩辰CAD-blue.svg)

一个**单文件** AutoLISP 工具。选中红线（多段线），按偏转角自动筛出真正的转角点，
批量生成「点号 / X=北 N / Y=东 E」三行坐标标注，并支持在图内直接生成坐标表、导出 CSV。

特点在于标注使用的是 **CAD 原生的多重引线（MLEADER）**：
标完之后点中文字、拖动夹点，引线会自动跟随重连，**不依赖任何 LISP 反应器**，图纸重开依然有效。

## 功能特性

| 特性 | 说明 |
| --- | --- |
| 转角自动筛选 | 按偏转角阈值筛选，或按目标角 ± 容差筛选，还能只挑左转 / 右转 |
| 原生多重引线 | 用 `vla-AddMLeader` 生成，文字可拖动，引线自动跟随，图纸重开仍有效 |
| 三行标准版式 | 点号 / X=北 N / Y=东 E，左对齐，水平肩线居中于三行高度正中 |
| 自动避让 | 每个标注在 7 个长度 × 11 个角度共 77 个候选位置里挑第一个不压盖的落点 |
| 重合点识别 | 距离小于判定值的点视为同一个点，自动跳过，不重复标注 |
| 图内坐标表 | 一键插入「界址点坐标表」，只含真正标注成功的点，不依赖 CAD 表格对象 |
| 批量导出 | 导出 CSV（点号、X 北、Y 东、原始 CAD 坐标、偏转角） |
| 错误可恢复 | 中途按 ESC 或出错会自动还原 `CMDECHO`、`CLAYER` 等系统变量 |

## 环境要求

- 支持多重引线（MLEADER）的 CAD：AutoCAD 2008 及以后版本、中望 CAD、浩辰 CAD
- Windows 桌面版 CAD（脚本用到 ActiveX 接口 `vl-load-com`）
- 需要能对当前图形做写操作

> 兼容性判断来自代码对各家 CAD ActiveX 接口的处理方式，**并非在全部版本上逐一实测**，
> 具体见 [已知限制](#已知限制)。

## 安装

### 单次加载

1. 命令行输入 `APPLOAD`，或菜单「管理 → 应用程序」
2. 选择本仓库根目录下的 `PTAGM.lsp`
3. 点「加载」，命令行出现 `PTAGM v2.1 已加载` 即成功

### 开机自动加载（推荐）

在 `APPLOAD` 对话框里点右下角「内容…」（宝箱图标）打开**启动组**，
把 `PTAGM.lsp` 加进去，之后每次打开图纸都会自动加载。

## 命令速查

| 命令 | 作用 |
| --- | --- |
| `ZB` | 转角点坐标批量标注（**主命令**，先跑它） |
| `ZBB` | 在图中插入「界址点坐标表」（只含已标注的点） |
| `ZBO` | 导出坐标 CSV 文件 |
| `ZBL` | 在命令行列出转角点坐标（不画任何东西） |
| `ZBD` | 清空标注图层，并复位结果表 |

旧版命令名 `PTAGM` / `PTAGMTAB` / `PTAGMOUT` / `PTAGMLST` / `PTAGMDEL` **仍然可用**，
代码里集中放在第 5 节，确认不需要后整块删掉即可。

> 想改命令名：只改 `PTAGM.lsp` **第 5 节**那五行 `defun c:XX`，其余逻辑不用动。

## 详细用法

### 一、`ZB` —— 批量标注

```
命令: ZB
选择对象:                      ← 框选红线（普通多段线 LWPOLYLINE）
筛选方式 [G/T] <G>:            ← 回车 = 按偏转角阈值筛选
偏转阈值(度) <30>:             ← 回车 = 30 度
转角方向 [A/L/R] <A>:          ← 回车 = 全部转角
文字高度 <视图高度的 2%>:       ← 回车 = 当前视图高度的 2%
坐标小数位 <3>:
测量点符号 [N/D/T] <N>:        ← N 无 / D 圆点 / T 三角箭头
引线长度 <3 倍字高>:
点号前缀 <J>:
起始编号 <1>:
重合点判定距离 <0.02 倍字高>:
标注图层 <坐标标注>:
  首点试算：X(北)=…  Y(东)=…   ← 先用第一个点给你看一眼，防止整批白标
  确认标注? [Y/Q] <Y>:
--- 完成：标注 N 个，跳过 M 个 ---
```

**参数说明**

| 参数 | 含义 |
| --- | --- |
| 筛选方式 | `G` = 偏转角绝对值 ≥ 阈值；`T` = 偏转角绝对值落在「目标角 ± 容差」内 |
| 转角方向 | `A` 全部 / `L` 只标左转角 / `R` 只标右转角 |
| 文字高度 | 直接回车时取当前视图高度的 2%，随图纸比例自动变化 |
| 测量点符号 | `D` 会额外画一个直径 0.32 倍字高的**空心细线圆**；`T` 会把引线箭头换成实心三角 |
| 引线长度 | 从转角点到引线折点的距离，默认 3 倍字高 |
| 重合点判定距离 | 小于该距离的点视为重复，跳过不标 |

**省事的做法**：一路回车到底，全部走默认值。

---

### 二、`ZBB` —— 图内坐标表

先跑过 `ZB` 才能用。依次回答表格字高、表格图层、左上角插入点。

- 表头：`点号 / X / Y / 边长`，上方是跨列的标题「界址点坐标表」
- 数据只取**标注成功**的点（`*PTAGM-LIST*` 里的内容），被跳过或标注失败的点不会混进来
- 用 `LINE` + `TEXT` 实体拼出来，**不用 AcDbTable 表格对象**，因此中望 / 浩辰同样能生成
- 默认画在标注图层上，所以 `ZBD` 清图层时会连表一起删

> `边长` 列的口径目前是：**本行点到表格下一行点的直线距离**，最后一行留空。
> 这不是沿红线的累计长度，如果需要改为累计长度或闭合边，请提 issue 或直接改代码。

---

### 三、`ZBO` —— 导出 CSV

导出表头为：

```
PT,X北N,Y东E,CADX,CADY,ANGLE
```

`CADX` / `CADY` 是未经换算的原始 CAD 坐标，`ANGLE` 是该点的偏转角（度）。

---

### 四、`ZBL` —— 命令行速览

选多段线、回答筛选条件后，只在命令行打印坐标，**不修改图纸**，适合先检查一遍。

---

### 五、`ZBD` —— 清理

按图层名删除该图层上当前布局内的所有对象，并把结果表复位。
表格默认画在标注图层上，所以清一次就把标注和表格一起清掉了。

## 坐标口径

**写死在代码里的换算规则：**

| 标注里的符号 | 含义 | 数据来源 |
| --- | --- | --- |
| `X` | 北坐标 N | 取 CAD 的 **Y** 值 |
| `Y` | 东坐标 E | 取 CAD 的 **X** 值 |

也就是把 CAD 的数学坐标系换成测量坐标系。需要反向的话，改这一行即可：

```lisp
(defun _pt-xf (p) (list (cadr p) (car p)))
```

## 常见问题

**Q：为什么我标注出来的点很少？**
A：默认的偏转阈值是 30 度，小于 30 度的转角会被跳过。把阈值调小，或者用 `T` 方式按目标角筛选。

**Q：引线和别人接的趋势图解里不一样 / 多出一段折返？**
A：本工具采用两点法，只给 CAD「测量点 + 折点」，水平肩线由 CAD 自动生成。
如果你的 CAD 仍多出折段，检查引线样式的 `MaxLeaderSegmentsPoints` 是否被改过，把 ZB 重跑一次会覆盖回去。

**Q：坐标 X、Y 反了？**
A：见[坐标口径](#坐标口径)，改 `_pt-xf` 一行。

**Q：想改默认图层、默认字高、默认小数位？**
A：`PTAGM.lsp` 第 1 节，所有默认值集中放在那里。

**Q：连续跑了好几次 `ZB`，导出的 CSV 里重复点号？**
A：`*PTAGM-LIST*` 是全局变量，重跑不会自动清空（这样可以分区域标注后统一导出）。
需要清的话先跑一次 `ZBD`，或者重新加载一次 `.lsp`。

## 已知限制

- `ZB` 这类两字母命令若与你本地其他插件撞名，改一下第 5 节的命令名即可
- 代码没有在所有 CAD 版本上逐一验证；较老的版本可能不支持个别多重引线属性，
  脚本已对这类属性做逐项容错（失败不影响其余属性），但极端情况下会发生符号层次差异
- 图内坐标表是 `LINE` + `TEXT` 拼装的散实体，不像原生表格那样能整体拖动调整行列
- 坐标表列的宽度按字符数估算，使用非等宽或特殊字体时可能略松略紧
